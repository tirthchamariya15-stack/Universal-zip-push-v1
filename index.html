Which permissions does the token need?

Classic token: the repo scope (or only public_repo for public repositories).

Fine-grained token: Contents: Read and write, Metadata: Read, and Administration: Read and write if you want to create repositories. Select the repositories (or all) it may use. Organization repositories may also need SSO authorization.

The token is sent only to api.github.com. It is never logged, shown again, uploaded or committed. If you tick “Remember”, it is kept in this browser’s local storage, so anyone using this browser profile or any script on this page origin could read it. Only run this app from a local or trusted origin.
